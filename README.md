## Technical Details
### Technologies/Components Used
For Software:
Software & Languages Used:
Languages: HTML5, CSS3, JavaScript (Vanilla JS)

Code Editor: Visual Studio Code – for writing and editing code

Browser: Google Chrome – for testing and running the project

Version Control: Git – for tracking code changes

Hosting: GitHub – for storing and sharing the project online

Operating System: Works on Windows, macOS, or Linux.
Frameworks Used
None – Built entirely with pure HTML, CSS, and JavaScript without frameworks like React, Angular, or Vue 
Libraries Used:
None – No external libraries or dependencies used; fully self-contained


For Hardware:
Hardware Used
Computer / Laptop – for writing, testing, and running the code

Processor: Any modern processor (Intel i3 / AMD Ryzen 3 or higher recommended)

RAM: Minimum 4 GB (8 GB recommended for smoother workflow)

Storage: At least 500 MB free space for project files

Display: Any monitor with 1366×768 resolution or higher

Internet Connection: For using GitHub and version control
